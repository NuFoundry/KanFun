# References

Drop anything you want the coding agent to look at here: screenshots of bugs, designs and
mock-ups, PDFs, customer emails, briefs, competitor pages, exports. Nothing in this folder is
committed (only this file is tracked), and the deploy images never see it.

- Name files by what they are: `bug-invoice-total.png`, `design-dashboard-v2.pdf`,
  `brief-onboarding.md`. A short note next to a screenshot helps ("the total is off by VAT").
- Mention a file in your message ("build the page in `design-dashboard-v2.pdf`"), or type
  `status`: the report lists every file here with a suggested action, numbered, so "do nr 4" works.
- Move a file to `references/done/` once it is acted on; the report skips that folder.
